# Contributing

Contributions that improve reproducibility, portability, tests, and documentation are welcome.

1. Create a focused branch.
2. Keep datasets, trained weights, generated results, and personal paths out of commits.
3. Run `python CODE/Computation/Main.py self-test` and `python -m unittest discover -s tests`.
4. Describe the scientific and software impact of each change.
5. Confirm that contributed code can be distributed under GPL-3.0-only.

Do not submit proprietary simulation data, unpublished manuscript files, access tokens, or third-party source code without a verified redistribution licence.
